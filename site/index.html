Open Car Project

Open the car you already own.

An open-source Android launcher for car head units.

What it does 🚗

Your dashboard, your grid

Long-press to move, push and resize cards, apps and widgets.

Notification island

Messages land in a bubble: tap to read and reply, tap outside to hide it.

Motion glow

The screen edge lights up as you turn, speed up or brake.

Speed scene

A live skyline that speeds up with you. Floor it and the car turns into a rocket.

See it running 📸

Run it / build it 🛠🤖

1Clone and build

Needs JDK 17+ and the Android SDK.

git clone https://github.com/<you>/open-car-project.git
cd open-car-project                      # default branch is develop
git remote add upstream https://github.com/maldos23/open-car-project.git
git config core.hooksPath .githooks      # rejects bad commit messages locally
export ANDROID_HOME=/path/to/android-sdk # or sdk.dir=... in local.properties (never commit it)
./gradlew test lintDebug assembleDebug   # same checks CI runs; first run downloads Gradle

2Install and set as HOME

Or skip the build: download the APK above.

./gradlew installDebug
adb shell cmd role add-role-holder android.app.role.HOME org.opencarproject.launcher

3Grant notification access

Powers the media card, notifications and next-turn hints.

PKG=org.opencarproject.launcher
adb shell cmd notification allow_listener $PKG/$PKG.data.source.LauncherNotificationListener
